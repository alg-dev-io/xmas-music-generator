
# 🎄 X-Mas Music Generator

Create your own Christmas music! 🎶

**X-Mas Music Generator** is an interactive web-based music creation tool that allows you to compose, play, customize, and record your own Christmas melodies directly from your browser.

Whether you want to experiment with melodies, play Christmas classics, use custom audio samples, or create your own sounds, this tool provides everything you need in one festive musical environment.

## ✨ Features

### 🎹 Interactive Music Keyboard
- Play musical notes in real time using an interactive virtual keyboard.
- Use your computer keyboard to play notes.
- Enjoy an interactive music creation experience directly in your browser.

### 🎛️ Grid-Based Music Sequencer
- Create melodies by drawing notes directly on a visual grid.
- Play, stop, and clear your sequences.
- Experiment with different musical patterns and compositions.

### 🎶 Christmas Demo Songs

Includes ready-to-play Christmas melodies:

- 🔔 Jingle Bells
- ⭐ Silent Night (Noche de Paz)

### 📁 Custom Audio Samples
- Upload your own audio samples or lead sounds.
- Supports MP3 and WAV audio files.
- Use custom audio as the sound source for your musical creations.

### 🎚️ Sound Customization

Adjust different audio parameters to personalize your music:

| Parameter | Description |
|---|---|
| Volume | Control the overall audio level. |
| Brightness / Filter | Adjust the tonal character of the sound. |
| Echo / Delay | Add spatial effects and repetitions. |
| BPM | Control the playback tempo (80–180 BPM). |

### 🔴 MP3 Recording & Export
- Record your musical creations directly from the application.
- Stop recordings whenever you want.
- Export and download your recordings as MP3 files.

### 🌍 Multilingual Interface

The application supports six languages:

- 🇪🇸 Spanish
- 🇬🇧 English
- 🇫🇷 French
- 🇩🇪 German
- 🇵🇹 Portuguese
- 🇮🇹 Italian

Switch languages directly from the interface.

### ❄️ Christmas Visual Experience
- Animated snowfall effect.
- Christmas-inspired interface and colors.
- Audio visualizer.
- Festive interactive design.

## 🛠️ Technologies Used

- **HTML5** – Application structure.
- **CSS3** – Styling, layout, and visual effects.
- **JavaScript** – Music engine, interactions, and application logic.
- **Web Audio API** – Audio generation and sound processing.
- **LameJS** – MP3 encoding and audio export.

## 🚀 Getting Started

No installation or build process is required.

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/x-mas-music-generator.git
```

### 2. Open the project folder

```bash
cd x-mas-music-generator
```

### 3. Run the application

Open `index.html` in your browser.

For the best experience, you can also run it using a local development server, such as the **VS Code Live Server** extension.

## 🎼 How to Use

1. **Load a sample:** Upload an MP3 or WAV file, or use the default synthesizer.
2. **Create music:** Play notes using the virtual keyboard or draw melodies in the sequencer.
3. **Explore demo songs:** Play Jingle Bells or Silent Night.
4. **Customize your sound:** Adjust volume, brightness, echo, and BPM.
5. **Record your creation:** Click the recording button to capture your music.
6. **Export your music:** Stop the recording and download your composition as an MP3 file.
